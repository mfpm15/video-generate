# Explicit no-Fal local demo or edit

Use this branch only when the user asks for no Fal/local-only work or agrees to it after the generative-provider limitation is explained. It does not verify MiniMax H3/Seedance, lipsync, Fal models, or generative character acting.

The upstream Ruby toolkit can render supplied artwork/footage with p5 camera moves, particles/light, titles, composition and FFmpeg assembly without a Fal call. Check local requirements with `python system/doctor.py --engine anime-local` when running inside the parent video repository. A Fal key is not a prerequisite for these strictly local tasks. Keep all media execution through the Ruby entry layer and its OOP wrappers, as in the main execution contract.

Ask what source artwork/footage exists, or use a legitimate image/local model tool that is actually available and authorized in the current executor. Claude Code by itself is not an installed image/video model. Never promise text-to-anime artwork generation offline merely because FFmpeg/Ruby is installed. If no assets or image model are available, finish the plan and report that precise prerequisite. Native image-generation tools in another application do not establish their availability on the user's laptop.

Initialize a separate project with `init --project ... --story ...`. Write the style contract and local-only plan, import the artwork with provenance, and author a p5 sketch. Local recipes include `anim:render`, `anim:prepare`, `anim:overlay`, `media:frame`, `media:sheet`, `media:concat` and `media:mux`. Use a thin project Rake task and a Ruby service calling `Media::Anim` / `Media::FFmpeg` when custom assembly is needed. No `plan:approve`, uploads, `gen:*` Fal generation, Whisper API or live tests are needed for a fully local sequence.

Source images may be stills; camera/parallax/compositing is not generative body motion. Label the result accurately as a local motion-comic/compositing demo. For silence requested by the user, export silent or with a measured silent track; do not synthesize fake speech or pretend ASR was checked. Preserve the requested aspect ratio/fps, verify frame count, keep critical text/face/focal objects inside the target safe rectangle and inspect actual frames. Encode from rendered source frames, using the intended colour matrix and faststart for delivery, to avoid unnecessary re-encoding or a landscape export preset that crops a portrait.

If the user requests moving characters, camera motion over a still is insufficient. Prepare appropriate transparent character/clean-plate assets with an authorized tool, animate a real local 2D rig (head, body, articulated arm/hand or other requested actions), and verify actor pixels change with the camera/background locked. Do not claim 2D puppetry is H3/generative acting. Add requested burned-in captions even when silent, using explicitly authored visual timings and safe placement, with no fake ASR evidence.
