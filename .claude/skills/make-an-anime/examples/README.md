# Examples

These four projects are here only to showcase example workflows: how a story becomes a plan, sheets, keyframes,
voices, a score, shots, an overlay, SFX and VFX, and how review changes a scene. They are not a house style.

**They must not influence the anime the user wants to make.** Take the user's characters, art style, palette, tone,
genre, pacing, editing, camera language and animation from the user's own story, references and brief. Never borrow
them from an example. Do not reuse an example's characters, designs, locations, voices, music, titles, fonts, colours,
shot lengths, cut rhythm or effects unless the user asks for that. When a brief leaves something open, ask the user or
derive the answer from their story, never from these files.

What to take from them is the mechanics: file layout, which step produces what, how prompts are phrased for each
model, how a shot pins its frames and audio, how a timing problem was found and fixed, and how a retake was decided.

| Example | Workflow it shows |
| --- | --- |
| `01-sample-seven` | The smallest complete project, read on every run: every step once, a quiet conversation, one tracked run, a title. |
| `02-final-inspection` | A slow drama: a held silence in the score, light drawn in p5 instead of by H3, hand-built pinned frames. |
| `03-riverbank-bout` | A fight: paper-cut panels instead of green screen, one tracked runner, contact in short retimed cuts, rejected sheets kept. |
| `04-too-salty` | A longer scene: a voice test, a reused take, held stills, handwriting in a keyframe, music gaps for a silence. |

`init --example NAME` copies an example in order to study or re-render that example. For the user's own anime, start
with `init --story`.
